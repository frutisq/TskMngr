# Task Manager

REST API для управления задачами, пользователями и комментариями. Учебный full-stack проект, разработанный для практики Java backend-разработки с использованием Spring Boot, PostgreSQL и Spring Security.

## Возможности

- **Управление задачами:** создание, просмотр, обновление и удаление задач.
- **Статусы и приоритеты:** изменение статуса задачи и управление её приоритетом.
- **Назначение исполнителей:** привязка пользователя к задаче.
- **Комментарии:** работа с комментариями к задачам.
- **Работа с пользователями:** получение списка пользователей и регистрация.
- **Аутентификация:** вход по имени пользователя и паролю, использование JWT.
- **Разделение слоёв приложения:** контроллеры, сервисы, репозитории, DTO и мапперы.
- **Тестирование:** unit-тесты сервисного слоя с использованием JUnit 5 и Mockito.

## Архитектура

Backend построен на слоистой архитектуре:

- **Controller** - обработка HTTP-запросов.
- **Service** - бизнес-логика приложения.
- **Repository** - доступ к данным через Spring Data JPA.
- **Entity** - сущности базы данных.
- **DTO** - объекты для передачи данных через API.
- **Mapper** - преобразование Entity в DTO и обратно.
- **Security** - аутентификация и обработка JWT.

## API

Основные группы endpoint'ов:

| Метод | Endpoint | Назначение |
|---|---|---|
| POST | `/api/auth/registration` | Регистрация пользователя |
| POST | `/api/auth/login` | Вход и получение токенов |
| GET | `/api/tasks` | Получение списка задач |
| GET | `/api/tasks/user/{userId}` | Получение задач пользователя |
| PATCH | `/api/tasks/{taskId}/assign/{userId}` | Назначение пользователя на задачу |
| GET | `/api/comments/task/{id}` | Получение комментариев к задаче |
| GET | `/api/users` | Получение списка пользователей |

### Пример регистрации

```http
POST /api/auth/registration
Content-Type: application/json
```

```json
{
  "username": "developer",
  "email": "developer@example.com",
  "password": "123"
}
```
### Пример входа

```http
POST /api/auth/login
Content-Type: application/json
```

```json
{
  "username": "developer",
  "password": "123"
}
```
При успешной аутентификации API возвращает access token и refresh token.

### Пример запроса с JWT

```http
GET /api/tasks
Authorization: Bearer <ACCESS_TOKEN>
```

Защищённые endpoint'ы требуют действительный токен. Доступ к конкретным операциям зависит от настроек Spring Security.

## Тестирование
Unit-тесты сервисного слоя проверяют основные сценарии работы с задачами, включая сохранение, получение, изменение статуса, обновление, назначение пользователя и удаление.

## Frontend

Frontend разработан на Vue 3. Он взаимодействует с backend через HTTP-запросы к REST API. Для отправки запросов используется Axios.

## Статус проекта
Учебный проект для практики backend-разработки на Java, работы с реляционной базой данных, построения REST API, тестирования и настройки аутентификации.
